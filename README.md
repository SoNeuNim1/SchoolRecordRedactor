# SchoolRecordRedactor v4.0.1 (공개용 소스 / Windows EXE 제작 패키지)

**학교생활기록부 개인정보 자동 삭제 · 모의면접 준비용**

제작: 소느님 · 문의: soneunim1@gmail.com

본 프로그램은 학교 현장 사용을 위해 제작한 **비공식 공개용 도구**이며 교육부·교육청·NEIS의 공식 프로그램이 아닙니다.

## 할 수 있는 일

- PDF 파일 여러 개 추가 후 한번에 변환 (원본은 보존)
- PDF마다 다른 페이지 수 자동 인식
- 첫 페이지: 사진·이름·성별·주민등록번호·주소 등 인적정보와 출신 중학교명 삭제
- 전 페이지: 학교명, 하단 날짜·출력자·출력 정보 삭제
- 하단 `학번 유지` / `이름 유지`를 따로 선택
- 출력 파일명 `기존파일명(모의면접용).pdf`
- 같은 이름의 기존 결과는 덮어쓰지 않음
- PDF는 **로컬 PC에서만** 처리; 파일을 외부 서비스에 업로드하지 않음

## 반드시 알고 사용할 점

이 프로그램은 **일부 양식에 맞춘 자동 삭제 프로그램이지 완전한 익명화 보증 도구가 아닙니다.**

- 학생 생활기록부의 활동, 세특, 경력, 수상 등 서술형 본문에서 학생이 간접적으로 식별될 수 있습니다.
- 학교명 제거는 PDF에서 검색 가능한 단어를 기반으로 합니다. 이미지 안에 쓰인 학교명, 분할된 글자, OCR이 되지 않는 텍스트는 남을 수 있습니다.
- 주민등록번호와 인적정보가 비정형으로 배치된 파일, 서식이 다른 학교, 스캔 이미지 PDF는 누락되거나 지원되지 않을 수 있습니다.
- **처리 결과의 모든 페이지**를 육안으로 확인해야 하며 개인정보가 남은 문서는 공유하면 안 됩니다.
- 원본 이름이 결과파일명에 그대로 남습니다. 개인정보가 들어 있는 원본 파일명이라면 **파일명도 개인정보입니다.** 공유용 파일은 별도로 변경하세요.
- `학번 유지` 또는 `이름 유지`를 켜면 해당 정보는 출력 PDF에 남습니다. 공개용 익명화가 아니라 내부 면접 관리용입니다.
- 학교 개인정보 관리 정책과 저작권·직무상 배포 가능 여부를 별도로 확인하세요.
- 보안 프로그램이 EXE를 차단한다면 학교 전산 담당자에게 문의하세요. 임의로 보안 예외 처리하지 마세요.

## 일반 선생님 사용 방법 (완성된 Windows EXE를 받은 경우)

1. 배포 ZIP을 풀고 `SchoolRecordRedactor.exe`를 더블클릭합니다.
2. `여러 PDF 추가` 또는 `폴더에서 PDF 추가`로 원본을 선택합니다.
3. `학번 유지`, `이름 유지`를 필요한 대로 선택합니다.
4. 파일별 결과 미리보기를 확인합니다. `삭제 후 보기`를 끄면 개인정보 포함 **원본**이 보이므로 화면 공유에 주의하세요.
5. `전체 자동 처리 · 저장` 버튼을 누릅니다.
6. `면접용_결과` 폴더에서 `기존파일명(모의면접용).pdf`를 확인한 뒤 모든 페이지를 검수합니다.

받는 PC에 Python이나 인터넷 연결은 필요하지 않습니다.

## 제작자: Windows EXE 빌드

게시할 자료 및 순서는 `docs/블로그_업로드_방법.md`를 먼저 읽어 주세요. **기존 EXE에는 이전 제작자 정보가 남아 있으므로 수정된 소스로 재빌드해야 합니다.**

**빌드하는 Windows PC에는 Python 3.10 이상과 최초 패키지 설치를 위한 인터넷이 필요합니다.** Windows 10/11 x64 권장.

1. 이 소스 ZIP 전체를 압축 해제합니다.
2. `01_build_onefile.bat` 더블클릭 (단일 EXE) 또는 `02_build_folder.bat` (폴더형)
3. 정상 빌드된 배포물은 `EXE_배포본` 폴더에 생성됩니다.
4. 일반 사용자에게 `SchoolRecordRedactor_v4.0.1_Windows_onefile.zip` 또는 폴더형 ZIP을 제공합니다.
5. 공개 게시물에는 **반드시 동일 버전의 SOURCE.zip과 제3자 오픈소스 소스 제공 방안**을 함께 준비하세요. 빌드 스크립트는 PyMuPDF 공식 소스 배포본 다운로드를 시도합니다.
6. 다른 Windows PC에서 실제 실행 확인 후 공개하세요. 현재 배포 패키지는 **Windows EXE 자체가 아니라 EXE 생성용 소스**입니다.

직접 소스 실행: Python이 설치된 PC에서는 `03_run_source.bat`을 실행합니다.

* 프로그램의 **도움말 > 프로그램 정보 / 오픈소스 라이선스**에서 저작권과 전문을 볼 수 있습니다.

* **최종 Windows 실행·누락 라이선스 검토 및 학교 내부 배포 승인 여부는 배포자에게 남아 있습니다.**
