제작: 소느님 · 문의: soneunim1@gmail.com

**먼저 확인:** 이 파일은 공개 준비 안내이며, 법률·보안 적합성을 최종 보증하지 않습니다.

## 1) 최신 소스에서 EXE 다시 빌드

1. 배포 패키지 ZIP을 **완전히 압축 해제**합니다.
2. Python 3.10+가 설치된 Windows 64비트 PC에서 `01_build_onefile.bat`을 실행합니다. (최초 빌드 시 인터넷 필요)
3. 성공하면 `EXE_배포본` 폴더에 아래 파일들이 생성됩니다.
   - `SchoolRecordRedactor_v4.0.1_Windows_onefile.zip` — 일반 사용자용; 내부 EXE는 Python 설치 없이 실행
   - `SchoolRecordRedactor_v4.0.1_SOURCE.zip` — 같은 소스의 공개용 파일
   - `pymupdf-1.26.7.tar.gz` — PyMuPDF 공식 소스 배포본, 빌더가 해시 검증 후 다운로드
   - `SchoolRecordRedactor_v4.0.1_onefile.sha256.txt` — EXE 파일 무결성 확인용
4. **기존에 만든 EXE는 표기가 자동으로 갱신되지 않으므로, 반드시 새로 빌드한 ZIP을 사용하세요.**
5. 프로그램 하단에 `제작 소느님 | 문의: soneunim1@gmail.com`이라고 나오는지 확인합니다.

폴더형이 필요하면 `02_build_folder.bat`을 별도로 실행하여 생성되는 `..._Windows_onedir.zip`을 배포하세요.

## 2) 외부 공개 전 검증

- 새 EXE를 Python이 설치되지 않은 Windows PC에서 실행합니다.
- `samples/`의 **가상 PDF**를 변환하여 4쪽과 12쪽의 페이지 수 및 삭제 결과를 전부 점검합니다.
- 지원하지 않는 PDF, 스캔 PDF, 이미지 기반 글자는 개인정보 삭제가 누락될 수 있습니다. 실제 생기부 테스트는 승인된 학교 환경에서만 진행합니다.
- 원본 파일명에 학생명이 포함되면 `(모의면접용)`으로 저장된 결과 파일명에도 남습니다. 외부 공유 시에는 파일명을 바꾸세요.
- **학생의 실제 생기부, 개인정보가 담긴 캡처, 학교 내부 자료는 공개 게시물·소스코드 저장소·버그 신고 메일에 첨부하지 마세요.**

## 3) 블로그 글 첨부 자료

일반 선생님에게는 **Windows 실행 ZIP**을 주요 다운로드로 안내합니다. 소스 ZIP과 PyMuPDF 소스는 라이선스·코드 검토용으로 별도 링크를 제공합니다. SHA-256 안내를 함께 올리면 무결성을 확인하는 데 유용합니다. 블로그의 파일 크기 제한으로 큰 PyMuPDF 소스를 첨부하기 어렵다면 접근 가능한 다른 배포 위치를 준비하세요. 단, 배포에 필요한 외부 라이브러리의 전체 대응 소스 제공 요건은 최종적으로 별도 확인이 필요합니다.

권장 배포 자료:

1. `SchoolRecordRedactor_v4.0.1_Windows_onefile.zip`
2. `SchoolRecordRedactor_v4.0.1_SOURCE.zip`
3. `pymupdf-1.26.7.tar.gz` 및 요구되는 다른 라이선스 대응 자료
4. `SchoolRecordRedactor_v4.0.1_onefile.sha256.txt`

배포물과 동일한 소스·라이선스 고지·빌드 방법을 지속 접근 가능하게 제공하고, `PUBLIC_RELEASE_CHECKLIST.md` 항목을 확인하세요.
