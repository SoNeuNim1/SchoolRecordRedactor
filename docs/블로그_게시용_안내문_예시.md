# SchoolRecordRedactor v4.0.1 — 생기부 개인정보 자동 삭제 프로그램 (모의면접용)

학교생활기록부 PDF에서 일부 인적정보, 학교명, 출력정보를 자동으로 삭제하는 **비공식 Windows용 오프라인 도구**입니다. 제작: 소느님 / 문의: soneunim1@gmail.com.

- 여러 PDF 일괄 변환 / 페이지 수 자동 인식 / 원본 보존
- 학번·이름 하단 표기 유지 여부 선택
- 파일명: `원본파일명(모의면접용).pdf`
- 인터넷 없이 PC 안에서 PDF 처리

**필독:** 완전한 익명화를 보장하지 않습니다. 실제 세특·활동 기록만으로 특정 학생을 알아볼 수도 있으며, 다른 양식·스캔 PDF에서는 개인정보가 남을 수 있습니다. **결과물의 모든 페이지를 확인하기 전에는 공유하지 마세요.** 출력 파일명에도 원본 학생 이름이 남을 수 있습니다.

본 프로그램은 교육부·시도교육청·NEIS의 공식 프로그램이 아닙니다. 학교의 개인정보 관련 규정에 맞는 용도로만 사용하세요. 이 프로그램의 Windows EXE는 학교 정책이나 보안 설정에 따라 실행이 제한될 수 있습니다. 오류 문의 시 실제 학생의 생기부나 개인정보가 포함된 파일·스크린샷은 이메일로 보내지 마세요. 가상의 자료나 개인정보를 제거한 오류 메시지로 문의해 주세요.

**첨부 다운로드**: Windows 실행 ZIP / 같은 버전 소스 ZIP / PyMuPDF 대응 소스 / SHA-256 체크섬 (게시자가 각각 확인 후 링크 삽입)
