## 소스 제공

Windows 실행 파일을 공개한다면 **동일 버전의 전체 소스, EXE 빌드 스크립트, 외부 라이브러리 소스에 대한 동등한 접근**을 제공해야 합니다.

빌드 명령 실행 시 다음을 생성하도록 구성되어 있습니다.

1. `SchoolRecordRedactor_v4.0.1_SOURCE.zip` : 본 프로그램 소스, 테스트, 가상 예시, 빌드 스크립트, AGPL 전문
2. `pymupdf-1.26.7.tar.gz` : 사용된 PyMuPDF 버전의 공식 소스 배포본 (약 84MB). PyPI 원본을 SHA-256으로 검사해 받아 둡니다. **빌드할 때 다운로드 성공 여부와 원본에 포함된 MuPDF 소스의 정확한 구성까지 확인하세요.**
3. `SchoolRecordRedactor_v4.0.1_Windows_onefile.zip` : EXE, 사용자 안내서, 저작권·라이선스 고지

셋 모두를 같은 블로그 글이나 동등한 공개 위치에서 접근할 수 있게 하세요. 실제 게시 전에 외부 소스 제공 범위 및 기타 종속성에 대한 AGPL 요건을 별도로 최종 확인해야 합니다.
